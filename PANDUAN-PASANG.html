Pasang Belajar Yuk! di HP 🌈

Game ini dipasang dari Google Chrome, tanpa Play Store. Setelah terpasang, ikonnya ada di layar utama dan bisa dipakai tanpa internet.

Android (Chrome)

  1. Buka link game dari penjual memakai Google Chrome.
  2. Tunggu sampai halaman menu tampil penuh (sekitar 10-30 detik pertama, file suara sedang disimpan).
  3. Ketuk menu titik tiga di kanan atas, pilih Pasang aplikasi atau Tambahkan ke layar utama.
  4. Buka dari ikon Belajar Yuk di layar utama.

Cara memakai

  • Ketuk ➕ Tambah Nama untuk menulis nama anak. Satu HP bisa menyimpan beberapa nama.
  • Pilih nama, lalu pilih permainan. Tombol 🔊 mengulang pertanyaan, 🏠 kembali ke menu.

Kalau suara tidak keluar

  • Ketuk 🔊 Tes Suara di menu utama dan periksa volume media.
  • Di Android, buka Pengaturan → Bahasa → Keluaran text-to-speech dan unduh suara Bahasa Indonesia.

Catatan

  • Pemasangan pertama butuh internet. Setelah itu game bisa dibuka offline.
  • Nama anak tersimpan di HP itu. Jika data Chrome dihapus atau aplikasi dilepas, nama perlu ditambahkan lagi.
  • Produk untuk satu keluarga. Dilarang membagikan atau menjual ulang link dan file ini.
